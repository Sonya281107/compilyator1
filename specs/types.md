# Система типов Ryst

## Встроенные примитивные типы (A.1.1)

| Тип    | Размер  | Диапазон                                               |
|--------|---------|--------------------------------------------------------|
| `i8`   | 1 байт  | −128 … 127                                             |
| `i16`  | 2 байта | −32 768 … 32 767                                       |
| `i32`  | 4 байта | −2 147 483 648 … 2 147 483 647                         |
| `i64`  | 8 байт  | −9 223 372 036 854 775 808 … 9 223 372 036 854 775 807 |
| `u8`   | 1 байт  | 0 … 255                                                |
| `u16`  | 2 байта | 0 … 65 535                                             |
| `u32`  | 4 байта | 0 … 4 294 967 295                                      |
| `u64`  | 8 байт  | 0 … 18 446 744 073 709 551 615                         |
| `f32`  | 4 байта | IEEE 754 одинарной точности                            |
| `f64`  | 8 байт  | IEEE 754 двойной точности                              |
| `bool` | 8 байт* | `true` / `false`                                       |
| `str`  | 8 байт  | Указатель на null-terminated строку                    |
| `void` | —       | Отсутствие значения (тип функций без return)           |

\* `bool` хранится как 64-битное слово для простоты (0 = false, non-zero = true).

## Числовые литералы и суффиксы

```
42         — тип i64 (по умолчанию)
42i32      — тип i32
42u8       — тип u8
0xFF       — шестнадцатеричный i64
0b1010     — двоичный i64
3.14       — тип f64 (по умолчанию)
3.14f32    — тип f32
```

## Массивы

```ryst
let a: [i64; 8] = [1, 2, 3, 4, 5, 6, 7, 8];
```

Массивы фиксированного размера. Размер является частью типа. Элементы хранятся на стеке непрерывно, каждый элемент — 8 байт (независимо от типа элемента). Доступ: `a[i]`. Проверка выхода за границы выполняется во время выполнения.

## Структурные типы

```ryst
struct Point { x: f64, y: f64 }
let p: Point = Point { x: 1.0, y: 2.0 };
```

Структуры являются значимыми (value) типами. Передаются по значению: поля последовательно занимают аргументные регистры или стековые слоты. Каждое поле занимает 8 байт.

## Интерфейсные типы (A.2.13)

```ryst
interface Shape { fn area(self: i64) -> i64; }
let s: Shape = some_rect;
```

Переменная интерфейсного типа — это fat pointer (16 байт):
- `[offset + 0]` — указатель на конкретный объект
- `[offset + 8]` — указатель на vtable

## Иерархия неявных расширений (A.1.8)

```
    u8 ──► u16 ──► u32 ──► u64 ──►─┐
                                    f32 ──► f64
    i8 ──► i16 ──► i32 ──► i64 ──►─┘
```

Следующие расширения выполняются неявно (без `as`):
- Любой целый тип расширяется до более широкого целого той же знаковости
- Любой целый тип расширяется до `f32`, `f32` — до `f64`
- В бинарных операциях оба операнда приводятся к «общему» типу

Сужающие преобразования (включая любой `float→int`) требуют явного `as`.

## Явное приведение типов

```ryst
let x: i32 = 42i64 as i32;   // сужение
let y: f64 = 3 as f64;        // расширение (явно)
```

`as` работает для любой пары примитивных числовых типов.

## Вывод типов (A.1.7)

Тип переменной без аннотации выводится из инициализатора:

```ryst
let x = 42;       // i64
let y = 3.14;     // f64
let flag = true;  // bool
let z = x + 1;    // i64 (тип x)
```

Тип возвращаемого значения функции без `-> T` выводится из `return`-операторов в теле.
