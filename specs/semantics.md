# Семантика языка Ryst

## Области видимости

Ryst использует лексические (статические) области видимости. Каждый блок `{}` открывает новую вложенную область видимости. Вложенные области видят имена из внешних; во внутренней области имя можно переопределить (shadowing).

Глобальная область содержит встроенные функции (`print`, `input`, `exit`, `panic`, `print_char`), все объявления на верхнем уровне программы и все `namespace`-пространства.

## Объявление переменных

```
let [mut] x [: T] = expr;
```

Без аннотации типа тип переменной выводится из правой части (type inference). Переменные, объявленные без `mut`, неизменяемы: повторное присваивание вызывает ошибку компиляции.

## Функции и перегрузка (A.2.8)

Функции с одним именем могут иметь разные сигнатуры. Перегрузка разрешается по точному совпадению числа параметров и их типов (с учётом неявных расширяющих приведений). Возвращаемый тип не участвует в разрешении перегрузки.

Функция без явного `-> T` получает тип возврата `void` или выводит его из `return`-операторов (A.1.7).

## Вывод типов (A.1.7)

- **Для переменных**: тип равен типу инициализирующего выражения.
- **Для функций**: если тип возврата не указан, семантический анализатор итерирует `return`-операторы в теле и определяет возвращаемый тип.

## Неявные расширяющие приведения (A.1.8)

Поддерживаются следующие неявные расширения:

```
i8 → i16 → i32 → i64
u8 → u16 → u32 → u64
i*/u* → f32 → f64
```

Сужающие приведения (например, `i64 → i32`) требуют явного `as`.

## Структуры

Структура объявляется ключевым словом `struct`. Поля хранятся на стеке. Структуры передаются по значению: при вызове функции поля разворачиваются в регистры (первые ≤6 полей — в `rdi, rsi, rdx, rcx, r8, r9`).

## Методы impl (A.2.12)

```ryst
impl Struct {
    [pub] fn method(self: Struct, ...) -> RetType { ... }
}
```

`self` — обычный первый параметр с типом структуры. Модификатор `pub` делает метод общедоступным; без него метод приватный (доступен только внутри `impl`-блока той же структуры).

Аналогично поля структур могут быть `pub` (по умолчанию) или `priv`.

## Перегрузка операторов (A.2.10)

Операторы `+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `<=`, `>`, `>=` могут быть перегружены для структур через специальные методы:

| Оператор | Метод         |
|----------|---------------|
| `+`      | `__add__`     |
| `-`      | `__sub__`     |
| `*`      | `__mul__`     |
| `/`      | `__div__`     |
| `%`      | `__mod__`     |
| `==`     | `__eq__`      |
| `!=`     | `__ne__`      |
| `<`      | `__lt__`      |
| `<=`     | `__le__`      |
| `>`      | `__gt__`      |
| `>=`     | `__ge__`      |

## Интерфейсы и динамический диспатч (A.2.13)

```ryst
interface I {
    fn method(self: SomePlaceholder) -> RetType;
}

impl Struct : I {
    pub fn method(self: Struct) -> RetType { ... }
}

let s: I = some_struct_var;  // fat pointer {data_ptr, vtable_ptr}
s.method();                   // вызов через vtable
```

Переменная интерфейсного типа хранит два машинных слова:
- `data_ptr` — указатель на конкретный объект на стеке
- `vtable_ptr` — указатель на vtable конкретного типа

Vtable — статический массив функциональных указателей в секции `.rodata`, созданный во время компиляции. Вызов метода через интерфейс — это `call [vtable_ptr + slot * 8]`.

## Встроенные функции

| Функция         | Описание                                          |
|-----------------|---------------------------------------------------|
| `print(x)`      | Вывести значение на stdout с переводом строки     |
| `print_char(c)` | Вывести один символ (i64 как ASCII-код)           |
| `input()`       | Прочитать строку со stdin                         |
| `exit(code)`    | Завершить процесс с кодом завершения              |
| `panic(msg)`    | Вывести сообщение об ошибке и завершить с кодом 1 |
